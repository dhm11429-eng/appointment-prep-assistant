# Appointment Preparation Assistant

## Description

The Appointment Preparation Assistant application allows users to organize their health concerns so they can create a printable copy before a doctor's appointment. The application has input options for symptoms, medication, patient questions, and additional concerns. The application does not give any medical advice. A disclaimer at the top of the website tells users about this and urges them to seek out a medical professional if there are medical concerns. All information that a user inputs remains private as a result of the application running in the browser with no external servers or databases.

## Setup

The application only uses CSS, HTML, and vanilla JavaScript; no libraries or frameworks were used. The first step to setting up the application is downloading or cloning the GitHub repository. The next step is to open the project folder and open the HTML file in the browser. After that, the application is ready to use.

## Usage

The first step in using the application is entering any symptoms that a patient is experiencing. The next step is to type in any medications the patient is taking and add them to the medication list using the Add Medication button. Then, the patient can type in any questions for their healthcare provider and any additional concerns. From there, the patient can generate a summary of the information they added using the Generate button. The last step in using the application is to click the Print Summary button to print the information.
